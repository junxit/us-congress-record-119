# Order of Procedure (Executive Calendar)

**Speaking:** Thune, John (T000250) [R-SD], Warren, Elizabeth (W000817) [D-MA]

```

  Mr. THUNE. Mr. President, I ask unanimous consent that the previous 
order with respect to the scheduled recess be modified so that the
```
