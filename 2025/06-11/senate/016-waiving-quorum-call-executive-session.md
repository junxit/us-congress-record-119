# Waiving Quorum Call (Executive Session)

**Speaking:** Barrasso, John (B001261) [R-WY], Schatz, Brian (S001194) [D-HI]

```
                          Waiving Quorum Call

  Mr. President, I ask unanimous consent to waive the mandatory quorum 
call with respect to the Long nomination.
  The PRESIDING OFFICER. Without objection, it is so ordered.
  Mr. BARRASSO. I yield the floor.
  I suggest the absence of a quorum.
  The PRESIDING OFFICER. The clerk will call the roll.
  The legislative clerk proceeded to call the roll.
  Mr. SCHATZ. Mr. President, I ask unanimous consent that the order for 
the quorum call be rescinded.
  The PRESIDING OFFICER. Without objection, it is so ordered.
```
