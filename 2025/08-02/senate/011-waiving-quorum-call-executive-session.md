# Waiving Quorum Call (Executive Session)

**Speaking:** Thune, John (T000250) [R-SD], Schumer, Charles E. (S000148) [D-NY]

```
                          Waiving Quorum Call

  Mr. President, I ask unanimous consent to waive the mandatory quorum 
call with respect to the Puzder nomination.
  The PRESIDING OFFICER. Is there objection?
  Without objection, it is so ordered.
  Mr. THUNE. I suggest the absence of a quorum.
  The PRESIDING OFFICER. The clerk will call the roll.
  The bill clerk proceeded to call the roll.
  Mr. SCHUMER. Mr. President, I ask unanimous consent that the order 
for the quorum call be rescinded.
  The PRESIDING OFFICER. Without objection, it is so ordered.
```
