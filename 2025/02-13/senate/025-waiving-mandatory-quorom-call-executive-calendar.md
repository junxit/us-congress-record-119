# Waiving Mandatory Quorom Call (Executive Calendar)

**Speaking:** Cruz, Ted (C001098) [R-TX]

```
                     Waiving Mandatory Quorom Call

  Mr. President, I ask unanimous consent that the mandatory quorum call 
with respect to the Lutnick and Loeffler nominations be waived.
  The PRESIDING OFFICER. Is there objection?
  Without objection, it is so ordered.
  Mr. CRUZ. Mr. President, I ask unanimous consent that the scheduled 
rollcall votes begin immediately.
  The PRESIDING OFFICER. Without objection, it is so ordered.
```
