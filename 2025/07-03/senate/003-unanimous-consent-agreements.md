# UNANIMOUS CONSENT AGREEMENTS

**Speaking:** Budd, Ted (B001305) [R-NC]

```
                      UNANIMOUS CONSENT AGREEMENTS

  Mr. BUDD. In my capacity as the Senator from North Carolina, I ask 
consent that notwithstanding the order of July 1, 2025, I be permitted 
to address the Senate to propound an order.
  The ACTING PRESIDENT pro tempore. Without objection, it is so 
ordered.
  Mr. BUDD. In my capacity as the Senator from North Carolina, I ask 
that the order of Tuesday, July 1, with respect to the Senate's 
reconvening be modified so that the Senate be in session on Monday, 
July 7, at 10:15 a.m. for a pro forma session only with no business to 
be conducted; and that the existing order for the Senate to reconvene 
on Monday, July 7, now occur on Tuesday, July, 8, with all other 
aspects of that order remaining in place.
  The ACTING PRESIDENT pro tempore. Without objection, it is so 
ordered.

                          ____________________
```
